# Consolidate project memory

The procedure is defined once, in `agents/AGENTS.md` under "Consolidation (`/consolidate-memory`)".
Read that section and follow it exactly. This file only exists so the command can be found by name.

The rules that matter most:
- Read all five files in `agents/` before changing any of them.
- Promote by rewriting the relevant section, not by appending. The permanent files must stay smaller than the log.
- Never silently change or remove an established rule. Every change goes in the report with its reason.
- Open questions and known gaps stay in WORKING_LOG.md.
- Add one line to "Consolidation history" at the bottom of WORKING_LOG.md.
- Finish with a report: what was promoted and where, rules changed and why, contradictions found, what's still open.
